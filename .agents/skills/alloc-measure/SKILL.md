# alloc-measure

**측정 전까지 가설이다.** v0.150.7~v0.152.5에 다섯 번 뒤집혔다.

1. **"GPU가 필요하다"를 먼저 의심한다.** 행이 그렇게 적었어도 대상이 순수 함수인 경우가
   많다 — 2026-08-20/21에 여덟 번 틀렸다. device를 안 받으면 필요 없다.
2. 공개 API로 닿으면 `tests/per_frame_alloc.rs`에 추가한다. 닿지 않으면 스크래치 단독
   바이너리(`rustc -O main.rs`). 모델링했으면 **모델임을 보고에 명시**한다.
3. 워밍업 2프레임 → 정상 상태 1프레임을 `measure()`로 감싼다. before/after는 **같은
   하니스에서** 잰다.
4. **대조군을 같이 돌린다** — 고치려는 경로 말고 **비싸지는 쪽**. 빠뜨리면 2배 회귀가
   초록으로 나간다.
5. 실물 코드는 `Arc::ptr_eq`/`ptr::eq` 동일성으로 고정한다. `assert_eq!`는 새로 할당된
   복사본에도 통과한다.
6. 할당 **수**와 **요청 바이트**를 함께 보고한다.

함정 여섯 가지는 `references/gotchas.md`.
