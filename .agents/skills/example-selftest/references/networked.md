# 네트워크 예제의 셀프테스트

살아 있는 전례는 **`netplay_game` 하나**다 — 2026-08-19에 삭제된 넷(`salvage_run`,
`predict_shooter`, `orbital_dodger`, `coin_race`)을 하나로 접은 것이고, 재건 과정에서
아래 규칙 두 개가 **뒤집혔다.** 삭제된 넷의 하니스를 기억으로 재현하지 말 것.

검사를 두 층으로 나눈다 — 서버 없이 도는 것(프로토콜 메시지를 `Events<NetworkEvent>`에
직접 주입, check 1-5)과 실서버를 띄우는 것(check 6-7).

## 서버 하니스

- **포트는 OS에서 받는다.** `TcpListener::bind("127.0.0.1:0")`으로 예약하고 즉시 drop한
  뒤 `<NAME>_ADDR` 환경변수로 자식에게 넘긴다. 원리적으로 경합이지만 옳은 트레이드다 —
  대안인 하드코딩 포트는 사용자가 이미 띄운 서버나 병렬 CI 잡과 충돌하는데, 서버는
  `expect`로 bind하므로 스킵이 아니라 **행-앤-페일**이 된다.
- **⚠️ 오버라이드는 공유 모듈에 둔다.** 삭제된 넷은 서버 쪽에만 두고 클라이언트는 상수를
  계속 다이얼했다. `netplay_game`은 `protocol.rs::server_addr()` **하나**를 두 바이너리가
  같이 부른다 — `CLAUDE.md`의 *"cfg-split backends share the policy"*가 여기에도 걸린다.
  wasm 브랜치는 읽을 환경이 없으므로 `#[cfg]`로 갈라 상수를 돌려준다.
- `<NAME>_ADDR`이 unset일 때 기존 상수와 **바이트 동일**해야 한다. 순수 additive다.
- **포트 번호는 삭제된 예제들의 것을 피한다.** `netplay_game`은 9006을 쓴다 — 9002~9005는
  삭제된 넷의 것이고, 포크가 `git show`로 하나를 되살려 나란히 돌릴 수 있어야 한다.
- **`NetworkClient::connect`는 재시도하지 않는다.** 생 `TcpStream::connect`로 바인딩될
  때까지 폴링(50 ms 간격, 10 s 데드라인)한 뒤에 붙는다. 먼저 붙고 기대하는 것은 느린
  경로가 아니라 **확정된 실패**다.

## ⚠️ 서버 바이너리가 없으면 실패다 — 스킵이 아니다

`example-selftest` 본문의 *"장치 없음은 `SKIP` + exit 0"*은 **여기에 적용되지 않는다.**

`netplay_game`은 exit **8**로 죽는다(바이너리 없음 · 포트 예약 실패 · spawn 실패 · 10초
안에 bind 안 됨). 근거는 측정이다 — 삭제된 트리의 네트워크 셀프테스트는 서버를 숨기면
raw exit code가 **0**이었고, 그게 하필 **가장 많이 커버하는 검사들**이었다.

`scripts/selftests.sh`도 오디오 외의 SKIP을 실패로 취급하므로 이건 벨트 앤 브레이스다.
**벨트가 필요한 이유**: 러너를 우회해 바이너리를 직접 돌리면 게이트 쪽 판정이 통째로
빠진다. 게이트는 `cargo build --example netplay_server`를 선행한다(목록은 `Cargo.toml`의
`[[example]]` 블록에서 유도).

## Gotchas

- **클라이언트를 다시 빌드해도 서버는 다시 빌드되지 않는다.** 사보타주한 서버 바이너리가
  revert 뒤에도 디스크에 남아, 깨끗한 트리에서 3회 연속 실패했다.
- **종단 상태 단언은 깜빡임을 놓친다.** 마지막에 한 번만 읽는 검사는 "축출됐다가 다음
  스냅샷에 되살아난" 엔티티를 통과시킨다. 매 프레임 관찰한다.
- **보간에는 워밍업 창이 있다.** 버퍼가 `interp_delay`보다 짧은 동안은 표시 위치와 최신
  스냅샷이 일치하므로, 그 구간에서 시작한 단언은 자기 반대를 증명한다. 워밍업은 셋업
  잡음이 아니라 성질의 일부다.
- **보간 지연은 "송신자가 실제로 있던 곳" 기준으로 잰다.** 최신 스냅샷은 이미 한 간격
  낡았다. 기준을 잘못 잡으면 37.5 px를 기대하고 17.5 px를 재고도 tolerance가 삼킨다.
- **비결정 요소는 불변식으로 단언한다.** 랜덤 리스폰이나 경합 승자가 있으면 점수 델타는
  못 센다. "얻은 점수 == 서버가 없앤 코인"처럼 양쪽 결과에서 모두 참인 것을 쓴다.
- **서버 검사는 `Instant`로 페이싱한다.** 서버는 벽시계로 tick하므로 오프라인 검사의
  고정 `dt`를 여기 쓰면 안 된다.

## 무엇을 노릴지

실패가 **플래터링한** 지점을 찾는다. 예측만 남고 보정이 죽으면 여전히 부드럽고, AOI
축출이 죽으면 HUD가 오히려 더 좋아 보이며, 클라이언트가 코인을 혼자 먹으면 싱글플레이에선
더 빠르다. 넷 다 스크린샷으로는 정상이고, 단일 창 플레이테스트로는 비교 대상조차 없다.
그게 이 검사들이 존재하는 이유다.

브라우저에서 도는 절반(wasm WebSocket)은 이 스킬이 아니라 `browser-smoke`다.
