# example-selftest — 함정

## 시간은 `Instant`로 잰다

`t += 1.0/60.0`으로 시계를 만들면 안 된다. `sleep`은 요청한 만큼을 **최소**로 자므로
누적 시계가 실제 경과보다 느려지고, 실시간 신호를 재는 검사가 조용히 어긋난다.

## `ENGINE_CAPTURE`로는 미터를 못 찍는다

캡처 실행은 고정 `1/60` dt로 CPU가 허용하는 최대 속도로 진행한다. 벽시계로 도착하는
것(오디오, 소켓, 파일 감시)은 캡처된 프레임에서 `0.0`으로 읽힌다 — 소리는 정상으로
나고 있는데도. 그것이 `<NAME>_SELFTEST`가 존재하는 이유다.

## 배경 스포너가 있으면 개수가 아니라 엔티티로 추적한다

코인 리스포너나 적 스포너가 도는 동안 "개수가 N이 됐다"를 단정하면, 세던 대상이
늘어나는 바람에 통과하거나 실패한다. **최종 상태가 아니라 불변식을 단정한다** —
특정 엔티티가 despawn 됐는지, 풀이 반환됐는지처럼.
