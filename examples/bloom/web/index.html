The engine's mip-chain "dual filter" bloom running on this browser's WebGL2 backend — the same engine code as the native example. Over-bright emitters glow with a wide soft halo; dim swatches below the threshold don't. Click Start, then on the canvas use B (real / inline bloom), ↑/↓ (intensity), ←/→ (pyramid depth). A self-check verdict (BLOOM_WEB_CHECK: PASS (1/1)) appears in the tab title once the HDR + Rgba16Float mip-chain bloom pipeline has rendered a few frames — float render targets need EXT_color_buffer_float here.
