Queries RenderCapabilities on this browser's WebGL2 backend and renders a yes/no table of which texture formats can be a color render target — the same engine code as the native example. Click Start: the per-format list logs to the console and a self-check verdict appears in the tab title (RENDER_FORMAT_QUERY_CHECK: PASS (2/2)). Float formats like Rgba16Float are renderable here only with EXT_color_buffer_float.
